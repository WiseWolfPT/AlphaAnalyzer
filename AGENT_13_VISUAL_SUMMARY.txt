  │  │ FMP Provider (Enhanced)                                      │ │
  │  │ ───────────────────────                                      │ │
  │  │                                                              │ │
  │  │ getQuote(symbol):                                            │ │
  │  │   1. normalize = mapper.normalizeFmpSymbol(symbol)           │ │
  │  │   2. alternatives = mapper.getAlternativeSymbols(symbol)     │ │
  │  │   3. FOR EACH variant IN alternatives:                       │ │
  │  │        TRY fetch(variant)                                    │ │
  │  │        IF success RETURN quote                               │ │
  │  │        ELSE continue to next                                 │ │
  │  │   4. IF all fail, throw error                                │ │
  │  │                                                              │ │
  │  │ getBatchQuotes(symbols):                                     │ │
  │  │   1. normalized = symbols.map(mapper.normalizeFmpSymbol)     │ │
  │  │   2. fetch(normalized.join(','))                             │ │
  │  │   3. return quotes                                           │ │
  │  └──────────────────────────────────────────────────────────────┘ │
  │                                ↓                                   │
