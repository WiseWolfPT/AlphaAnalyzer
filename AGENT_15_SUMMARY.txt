                              THE SOLUTION
================================================================================

Multi-Provider Fallback Chain:

  Priority 1: FMP (primary)           → 300/min, 750/day
      ↓ (if missing/failed)
  Priority 2: Alpha Vantage           → 5/min, 500/day
      ↓ (if missing/failed)
  Priority 3: Polygon.io (NEW)        → 5/min, 500/day
      ↓ (if missing/failed)
  Priority 4: Yahoo Finance (NEW)     → Unlimited (free)

Key Features:
  ✅ Per-data-type fallback (smart partial data recovery)
  ✅ Rate limit awareness (skips providers near 95% quota)
  ✅ Health tracking (skips providers with >5 failures)
  ✅ Completeness scoring (0-100% per stock)
  ✅ Zero overhead when primary succeeds
  ✅ Observable via 3 monitoring endpoints

                            INTEGRATION GUIDE
================================================================================

Step 1: Install Dependencies
  npm install yahoo-finance2 axios

Step 2: Configure Environment (.env.production)
  FMP_API_KEY=your_fmp_key                      # Required
  ALPHA_VANTAGE_API_KEY=your_alpha_key          # Required
  POLYGON_API_KEY=your_polygon_key              # Optional
  # Yahoo Finance requires no API key

Step 3: Initialize Orchestrator (server/index.ts)
  import { DataProviderOrchestrator } from './services/data-provider-orchestrator';
  import { FMPProvider } from './services/providers/fmp-provider';
  import { AlphaVantageProvider } from './services/providers/alpha-vantage-provider';
  import { PolygonProvider } from './services/providers/polygon-provider';
  import { YahooFinanceProvider } from './services/providers/yahoo-finance-provider';
  import dataFallbackRoutes, { initDataFallbackMonitoring } from './routes/monitoring-data-fallbacks';

  const providers = [];
  if (process.env.FMP_API_KEY) providers.push(new FMPProvider(process.env.FMP_API_KEY));
  if (process.env.ALPHA_VANTAGE_API_KEY) providers.push(new AlphaVantageProvider(process.env.ALPHA_VANTAGE_API_KEY));
  if (process.env.POLYGON_API_KEY) providers.push(new PolygonProvider(process.env.POLYGON_API_KEY));
  providers.push(new YahooFinanceProvider());

  const dataOrchestrator = new DataProviderOrchestrator(providers);
  initDataFallbackMonitoring(dataOrchestrator);
  app.use('/api/monitoring', dataFallbackRoutes);
  export { dataOrchestrator };

Step 4: Use in Controllers
  // Before (FMP only)
  const quote = await fmpProvider.getQuote(symbol);

  // After (Multi-provider fallback)
  const data = await dataOrchestrator.getFinancialData(symbol);
  const quote = data.quote;
  console.log(`Completeness: ${data.completeness}%`);

Step 5: Monitor in Production

Common Issues & Solutions:

Issue 1: High Fallback Usage (>30%)
  Symptoms: /api/monitoring/data-fallbacks shows >30% fallback
  Diagnosis: curl .../data-providers | jq '.providers[] | select(.name=="FMP")'
  Solutions:
    - Check FMP rate limit (if >95%, increase limit or reduce frequency)
    - Check FMP health (if failures >5, investigate API key/network)
    - Check FMP status: https://financialmodelingprep.com/status

Issue 2: Low Completeness (<80%)
  Symptoms: /api/monitoring/data-quality shows <80%
  Diagnosis: curl .../data-quality | jq '.quality_metrics'
  Solutions:
    - Check all provider statuses (ensure 4 healthy)
    - Verify API keys in .env.production
    - Test individual providers with validation script
    - Check for sector-specific data availability

Issue 3: Provider Unhealthy
  Symptoms: Provider status = "unhealthy"
  Diagnosis: curl .../data-providers | jq '.providers[] | select(.status=="unhealthy")'
  Solutions:
    - Wait 5 minutes for auto-recovery
    - Check provider API status page
    - Verify API key validity
    - Check network connectivity

Issue 4: Rate Limit Exceeded
  Symptoms: Provider rate_limit.status = "critical"
  Diagnosis: curl .../data-providers | jq '.providers[].rate_limit'
  Solutions:
    - Reduce request frequency
    - Increase rate limit buffer (default 95% → 90%)
    - Upgrade to paid tier (if available)
    - Distribute load across more providers
