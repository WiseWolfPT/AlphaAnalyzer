5 PADRÕES DE FALHA (Identificados & Analisados)
================================================================================

TIPO 1: Missing Profile (5-10% das falhas)
  Exemplo: LLY, BA, JPM, BAC, STBX, RH
  Causa: FMP API não retorna profile (possível símbolo alternado)
  Solução: Tentar LLY-US, BA-US, etc. → Esperado resolver 5-7 stocks
  Tempo: 1 hora
  
TIPO 2: Missing Cash Flow (3-5% das falhas)
  Exemplo: Recentes IPOs, SPACs, startups
  Causa: Menos de 5 anos de histórico financeiro
  Solução: Usar modelos alternativos (P/E, P/S, P/B) já implementados
  Tempo: Já feito (usar auto-fallback)

TIPO 3: ETFs & Índices (0% cobertura, ~3-5% do universo)
  Exemplo: XLE, XLU, XLP, SPY, QQQ
  Causa: Estrutura de investimento não aplicável a DCF
  Solução: Detectar explicitamente, retornar erro amigável
  Tempo: 30 minutos

TIPO 4: Negative/Zero FCF (10-15% das falhas)
  Exemplo: AMZN ($38.17 LOW), TSLA ($17.84 MED), empresas growth
  Causa: Growth companies reinvestem tudo (FCF negativo)
  Solução: Marcar como LOW confiança, indicar estrutura agressiva
  Status: Já funciona (retorna resultado com LOW confidence)

TIPO 5: Micro-cap Sem Dados (100% dos micro-caps)
  Exemplo: AFRM, RIOT, MARA, SOFI, CLSK
  Causa: FMP prioriza large/mid-cap, cobertura limitada
  Solução: Detectar market cap < $2B, retornar LOW ou erro informativo
  Tempo: 1 hora

PRÉ-REQUISITOS NECESSÁRIOS (Cascade de Validação)
================================================================================

Para calcular IV, o sistema precisa de:

  1. Company Profile (FMP /api/v3/profile/:ticker)
     Status: 99% cobertura
     Se faltar: → Erro "No profile data found"
     
  2. Cash Flow History 5 anos (FMP /api/v3/cash-flow-statement/:ticker)
     Status: 95% cobertura
     Se faltar: → Erro "No cash flow data found"
     
  3. Balance Sheet (FMP /api/v3/balance-sheet-statement/:ticker)
     Status: 95% cobertura
     Se faltar: → Erro "No balance sheet data found"
     
  4. Shares Outstanding (7-tier fallback cascade)
     Status: 90% cobertura
     Fallbacks: key-metrics → key-metrics-ttm → balance-sheet → 
               income-statement → quote → profile → income+quote
     Se faltar TODOS: → Erro "Shares unavailable"

Se QUALQUER um desses faltar → IV não pode ser calculada

ANÁLISE DE CONFIANÇA

Os 91% que funcionam têm distribuição de confiança:

  HIGH Confidence (60% do universo)
    • Beta ≠ default
    • Todos dados vêm do FMP (não fallback)
    • FCF > 0 nos últimos 5 anos
    
  MED Confidence (30% do universo)
    • Beta = default (fallback) OU
    • RF/MRP = fallback OU
    • Estrutura normal mas alguns dados parciais
    
  LOW Confidence (10% do universo)
    • FCF negativo (growth companies)
    • Dados incompletos
    • Micro-cap ou recente IPO

Nota: 91% retorna MED/HIGH, 9% não calcula
