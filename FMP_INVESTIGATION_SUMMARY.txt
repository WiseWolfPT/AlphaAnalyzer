INVESTIGATION GOAL
Investigate the FMP (Financial Modeling Prep) Legacy documentation at
https://site.financialmodelingprep.com/developer/docs/legacy to find the
correct endpoint for after-hours and pre-market stock price data.

CRITICAL FINDINGS SUMMARY
=========================

1. STANDARD /api/v3/quote INCLUDES EXTENDED HOURS DATA
   Answer: YES (partially)
   Evidence: fmp-provider.ts lines 98-104
   
   The standard /api/v3/quote endpoint INCLUDES these optional fields:
   - afterMarketPrice
   - afterMarketChange
   - afterMarketChangePercentage
   - preMarketPrice
   - preMarketChange
   - preMarketChangePercentage
   
   NOTE: Fields are NULL when no data is available for that session.

2. CORRECT ENDPOINTS FOR AFTER-HOURS DATA
   Answer: Use dedicated stable endpoints
   
   Primary Endpoints (Recommended):
   - /stable/aftermarket-quote (after-hours single symbol)
   - /api/v4/pre-market-quote (pre-market single symbol)
   - /stable/batch-aftermarket-quote (after-hours batch)
   
   Fallback:
   - /api/v3/quote (includes both when available)

3. EXACT FIELD NAMES IN RESPONSES
   From /stable/aftermarket-quote:
   - bidPrice or bid (ask vs bid)
   - askPrice or ask
   - volume
   - timestamp
   
   From /api/v4/pre-market-quote:
   - bid
   - ask
   - volume
   - timestamp
   
   From /api/v3/quote extended fields:
   - afterMarketPrice, afterMarketChange, afterMarketChangePercentage
   - preMarketPrice, preMarketChange, preMarketChangePercentage

4. BATCH REQUEST SUPPORT
   Answer: YES (with limitations)
   
   Batch Endpoints Available:
   - /stable/batch-aftermarket-quote (YES - supports up to 20 symbols)
   - /api/v3/quote (YES - supports up to 20 symbols comma-separated)
   - /api/v4/batch-pre-market-quote (NO - not available on Starter plan)
   
   Workaround: Fetch pre-market individually, cache for 30 seconds

5. RATE LIMITS
   Answer: 300 requests/minute (Starter plan)
   
   Current Implementation: 290 req/min (10-call safety buffer)
   
   Extended Hours Request Cost:
   - Single symbol: 2 API calls (after + pre in parallel)
   - Batch (20 symbols): 1 API call

   - Use parallel Promise.all() for performance
   - Cache results 30 seconds

2. After-Hours Volume is Estimated
   - Display with caveat: "Volume (estimated)"
   - Less reliable than regular hours volume
   - For informational purposes only

3. Data Freshness Varies
   - Extended hours data updates less frequently
   - Show last update timestamp to users
   - Consider 30s as minimum viable TTL

4. Batch Maximum: 20 Symbols
   - Split larger requests into batches
   - Each batch = 1 API call
