VALIDATION METHODOLOGY ISSUES
================================================================================

WHAT WENT WRONG:
  1. Used live API endpoint (triggers fresh FMP calls)
  2. Underestimated rate limit amplification (1 → 10-15x)
  3. Did not pre-warm cache before validation
  4. Did not account for stale failure states in cache

WHAT SHOULD HAVE BEEN DONE:
  1. Pre-warm cache for test universe (24-48h before validation)
  2. Validate against cached data only (no live API calls)
  3. Segment test universe by priority (US Tier 1/2, International)
  4. Add cache-only validation mode to backend
