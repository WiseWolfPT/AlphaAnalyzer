ROOT CAUSE CHAIN
====================================================================

1. Validation script runs → Makes 1,500 API calls rapidly
2. FMP rate limit hit → Returns HTTP 429
3. fmpGet() catches error → Returns null (no error type distinction)
4. null interpreted as "No profile data found"
5. Error thrown → All 20+ valuation methods fail
6. Failed result cached in Redis → No TTL differentiation
7. Subsequent requests → Serve cached failures forever
8. Validation reports → Show "HTTP 404" but actually cached 429s

PERMANENT FIX (5 hours)
====================================================================

Code changes needed in /server/services/valuation-service.ts:

1. Distinguish error types in fmpGet():
   - HTTP 429 → throw RateLimitError (retry)
   - HTTP 404 → return null (expected failure)
   - HTTP 5xx → throw APIError (retry)
   - Timeout → throw NetworkError (retry)

2. Add retry logic with exponential backoff:
   - Rate limit: 2s, 4s, 8s delays
   - Network error: 1s, 2s, 3s delays
   - Max 3 retries

3. Differentiate cache TTL:
   - Success: 1 hour
   - Not found (404): 24 hours
   - Errors (429, timeout): 5 minutes
