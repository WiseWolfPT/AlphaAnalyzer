  1. Check worker uptime (pm2 status)
  2. View warming worker logs
  3. Check bandwidth usage
  4. Verify API key valid

Problem: Bandwidth alert
  1. Check monthly usage vs 20 GB limit
  2. Review daily trends (7-day history)
  3. Identify top API consumers
  4. Consider warming frequency adjustment

  2. Verify network connectivity
