PROBLEM STATEMENT
================================================================================

Current rate limiter (capacity=4, rate=4) doesn't handle burst traffic.
When 8 parallel batch calls are made (warming worker), HTTP 429 errors occur.

Root Cause: No burst allowance - all calls compete for same 4 tokens/sec rate.

================================================================================
SOLUTION DELIVERED
================================================================================

Production-grade token bucket rate limiter with:

1. BURST ALLOWANCE
   - 8 tokens capacity
   - Allows 8 simultaneous calls instantly
   - Zero waiting for first 8 calls

2. SUSTAINED RATE
   - 4 tokens/sec refill rate
   - Matches FMP limit
   - Predictable throttling after burst

3. ADAPTIVE RATE LIMITING
   - Detects HTTP 429 errors
   - Automatic exponential backoff (5s, 10s, 20s, 40s)
   - Self-healing on success

4. COMPREHENSIVE MONITORING
   - Real-time state (tokens, utilization)
   - Statistics (calls, success rate, wait times)
   - Health checks with issue detection
   - Performance metrics
